HTML Tags and Their Descriptions

<!DOCTYPE html>
A declaration that tells the browser the document is written in HTML.
<html>
The root element that wraps all the other HTML code on the webpage.
<head>
A container for information about the webpage, such as its title and links to CSS stylesheets.
<title>
Defines the text that appears in the browser tab.
<body>
Contains the visible content displayed on the webpage.
